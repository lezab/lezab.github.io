    MCacheViewer

    Overview

    MCacheViewer is a command-line tool that allows viewing and inspecting the content of cache files created by the MCache class from the mlib library. This tool is particularly useful for debugging and analyzing cached data.

    Features

    • Reading and decoding MCache cache files
    • Formatted display of serialized data
    • Support for different data types (arrays, objects, strings, etc.)
    • Simple and intuitive command-line interface
    • Clear error message handling

    Installation

    mcacheviewer is structured as follows:

    - mcacheview       <-- bash file
- mcacheviewer/
    - mcacheview.php
    1. Copy everything to a directory of your choice (for example /usr/local/bin/)
    2. Make the script executable:
      chmod +x /path/to/mcacheviewer/mcacheview
    3. If the directory is not in your PATH, add it or use the full path

    Usage

    Basic Syntax

    mcacheview -f <cache_file>

    Available Options

    Option Description
    -h, -?, --help Displays help message
    -v, --version Displays tool version
    -f, --file Specifies the cache file to view

    Usage Examples

    View a specific cache file

    # Using the bash script
mcacheview -f /var/www/cache/my_key.cache

# Using PHP directly
php /path/to/mcacheviewer/mcacheview.php -f /var/www/cache/my_key.cache

    Display help

    mcacheview -h

    Display version

    mcacheview -v

    Cache File Format

    MCacheViewer is designed to read cache files generated by the MCache class. These files have the following structure:

    • Extension: .cache
    • Format: Data is serialized with serialize(), then base64 encoded
    • Content: A single line containing the encoded data

    Output Examples

    For a string

    $ mcacheview -f /tmp/message.cache
Hello world!

    For an associative array

    $ mcacheview -f /tmp/config.cache
Array
(
    [database] => mysql
    [host] => localhost
    [port] => 3306
    [username] => admin
    [password] => *****
)

    For an object

    $ mcacheview -f /tmp/user.cache
User Object
(
    [id:User:private] => 42
    [name:User:private] => John Doe
    [email:User:private] => john@example.com
    [createdAt:User:private] => 2025-01-15 10:30:00
)

    Use Cases

    Application Debugging

    MCacheViewer is particularly useful for:
    - Verifying that data is properly cached
    - Inspecting cache content during development
    - Diagnosing corrupted cache problems

    Cache Monitoring

    # Check content of a specific cache
mcacheview -f /var/www/app/cache/user_123.cache

# Script to check multiple cache files
for file in /var/www/app/cache/*.cache; do
    echo "=== $file ==="
    mcacheview -f "$file"
    echo ""
done

    Data Migration

    # Export cache content to a readable file
mcacheview -f /tmp/old_cache.cache > /tmp/cache_content.txt

    Error Handling

    File Not Found

    $ mcacheview -f /nonexistent/path.cache
File not found : /nonexistent/path.cache

    Corrupted Cache File

    If the cache file is corrupted or not in the expected format, MCacheViewer will display PHP errors related to deserialization.

    Invalid Arguments

    $ mcacheview --unknown-option
Unknown arg : unknown-option

mcacheview v1.0.0

Usage :
mcacheview.php -h
mcacheview.php -f <filename>

<args>  
    -h, -?, --help :

            leads to this message

    -v, --version :

            Gives the version

    -f, --file :

        The path to a file containing data from MCache

    Arguments with options accept these formats ("a" is the short format argument, "aaa" is the long format argument, "option" is the option):
    -a option
    --aaa option
    --aaa=option

    Integration with Other Tools

    Combination with grep

    # Search for a specific value in all cache files
for file in /var/www/cache/*.cache; do
    result=$(mcacheview -f "$file" | grep "search_term")
    if [ ! -z "$result" ]; then
        echo "Found in $file:"
        echo "$result"
    fi
done

    Combination with jq (for JSON data)

    # If cached data is JSON
mcacheview -f /tmp/data.cache | jq '.key'

    Best Practices

    1. Permissions: Ensure the user running MCacheViewer has read permissions on cache files.

    2. Security: Cache files may contain sensitive data. Use MCacheViewer with caution in production environments.

    3. Performance: For large cache files, display may take time. Use tools like head or grep to filter output if necessary.

    4. Backup: Before manipulating cache files, it's recommended to make a copy.

    Troubleshooting

    Problem: Permission denied

    $ mcacheview -f /var/www/cache/test.cache
Permission denied

    Solution: Check file and directory permissions:

    ls -la /var/www/cache/test.cache
chmod 644 /var/www/cache/test.cache

    Problem: Empty file

    $ mcacheview -f /tmp/empty.cache

    Solution: The cache file is probably empty or corrupted. Verify that MCache properly wrote the data.

    Problem: Unreadable data

    $ mcacheview -f /tmp/binary.cache
<unreadable binary data>

    Solution: The file is probably not a valid MCache cache file. Verify that the file was created by the MCache class.
